# Backlog inicial e sprints planejadas

Este backlog descreve o escopo planejado. Não comprova reuniões ou atividades que não tenham sido efetivamente realizadas.

## Product Backlog
1. Criar interfaces e componentes reutilizáveis.
2. Implementar Template Method e aplicações concretas SECOMP/Simpósio.
3. Criar Event Service com SQLite e CRUD.
4. Criar Participant Service com SQLite e CRUD.
5. Criar Registration Service com SQLite e ciclo de inscrição.
6. Implementar API Gateway.
7. Construir interface web simples.
8. Testar integração e documentar arquitetura.

## Sprint 1 — Framework
- Interfaces abstratas.
- Componentes reutilizáveis.
- EventFramework e Template Method.
- Classes concretas e testes unitários.

## Sprint 2 — Microservices
- Event Service.
- Participant Service.
- Registration Service.
- Bancos SQLite independentes.

## Sprint 3 — Integração e entrega
- API Gateway.
- Interface web.
- Testes de integração.
- Diagramas e documentação.

Datas, responsáveis e status real devem ser preenchidos pela equipe conforme o trabalho efetivamente realizado.
